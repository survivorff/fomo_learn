## 2. 三层增长机制

Odaily 的拆解很到位（措辞已改写）：围绕用户增长和社交交易，fomo 建了三套相互咬合的机制 —— **Clans、Trader Rewards、Referral**。

```
╔════════════════════════════════════════════════════════════╗
║  第一层：分发（把人拉进来）                                     ║
║  ────────────────────────────────────────                 ║
║  Referral：推荐人拿被推荐用户手续费的 25%                       ║
║            被推荐用户拿 10% 费率折扣                           ║
║  → 把分发成本变成变动成本，KOL 变成销售团队                       ║
╚════════════════════════════════════════════════════════════╝
                            ↓
╔════════════════════════════════════════════════════════════╗
║  第二层：内容（让人留下来）                                     ║
║  ────────────────────────────────────────                 ║
║  Trader Rewards：分享观点/Thesis，促成他人交易即获实时奖励        ║
║  → 把「输出内容」变成有直接经济回报的行为                          ║
╚════════════════════════════════════════════════════════════╝
                            ↓
╔════════════════════════════════════════════════════════════╗
║  第三层：归属（让人回来）                                       ║
║  ────────────────────────────────────────                 ║
║  Clans：战队、独立 Feed、独立周榜、战绩卡                        ║
║  → 把个人交易变成团队活动，引入社交义务与竞争                       ║
╚════════════════════════════════════════════════════════════╝
```

## 3. Referral：25% 分成的杀伤力

### 3.1 机制

**[三方 Odaily，引 fomo 2026-06-02 官方公告]**

| 角色 | 得到什么 |
|---|---|
| **推荐人** | 被推荐用户产生的**交易手续费的 25%** |
| **被推荐用户** | **交易手续费 -10%**，账户存续期间长期有效 |

累计已付返佣在 2026-06-02 时已超 **$2M**。

### 3.2 为什么 25% 是个激进的数字

对比行业常见的推荐分成（10–20%），25% 明显偏高。代价是：

```
名义费率              0.50%
减推荐码折扣 -10%  →  0.45%
减推荐人分成 -25%  →  0.3375%  归平台
```

**被推荐用户的平台 take rate 只有名义费率的 67.5%。**

但换来的是：**日新增 3 万用户，且不花广告预算**。

### 3.3 观察到的现象

Odaily 记录了 2026 年 8 月的场景（措辞已改写）：社交平台上盈利截图频繁流传，收益动辄几十万到上百万美元；同时大量 KOL 开始密集分享自己的 fomo 推荐码，直接把粉丝导流到平台。

**这不是自发好评，是被经济机制驱动的分发。** 网络上大量的 `fomofamily.com` / `fomotrading.app` / `fomoapp.trade` / `fomo.radio.fm` 一类站点，全部是联盟推广站，内容多数准确但带返佣动机。

### 3.4 自建建议

| 项 | 建议 |
|---|---|
| **分成比例** | 起步可以给到 25–30% 抢 KOL，规模后降到 15–20% |
| **分成是否永久** | fomo 是永久。永久的获客成本可控但毛利永久受损；建议做**阶梯递减**（首年 30%，之后 15%） |
| **折扣是否永久** | fomo 的 -10% 是永久。这是强承诺，建议保留 —— 它是用户选择你而非竞品的理由 |
| **归因链路** | 必须做到精确可对账。这是 KOL 信任的基础，算错一次就没人推了 |
| **防刷** | 自推自（同一人注册多号）、机器人注册、刷量套返佣，都要检测 |
| **KOL 分层** | 头部 KOL 给定制分成和数据看板，中长尾走标准分成 |

⚠️ **必须提前想清楚的一件事**：25% 分成 + 10% 折扣意味着你的费率下限被锁死了。如果未来要打价格战，这个结构会让你没有空间。

## 4. Trader Rewards：给内容生产者付钱

### 4.1 机制

**[三方 Odaily，引 fomo 2026-08-28 发布]**

用户在平台上分享交易观点或投资论述（Thesis）。**如果这些内容促使其他用户执行交易，发布者可以实时获得相应奖励。**

⚠️ **fomo 未公开具体计算公式、奖励比例或适用交易范围。** 不应简单理解为固定返点比例。

有报道称该计划承诺 $2M 量级的支出 **[未验证]**，用于与 Pump.fun 一类平台的创作者激励竞争。

### 4.2 为什么这个机制很聪明

它解决了社交产品最根本的矛盾：**内容生产者凭什么免费给你干活？**

```
传统社交产品：
  内容生产者靠「粉丝/虚荣心」驱动 → 供给不稳定
  或者平台掏广告分成 → 与内容质量脱钩

fomo 的做法：
  内容 → 促成交易 → 交易产生手续费 → 分一部分给内容生产者
        ↑                                    ↓
        └────────── 闭环，自我供给 ─────────────┘
```

**内容质量与平台收入直接挂钩** —— 写得好的 Thesis 带来更多交易，作者拿更多奖励。这比广告分成精准得多。

### 4.3 风险

| 风险 | 说明 |
|---|---|
| **激励写「能带单的内容」而非「对的内容」** | 最能带单的是煽动性内容，不是审慎分析 |
| **与出货流动性叠加** | 作者既有奖励收入，又有粉丝抬轿的收益 —— 双重激励去喊单 |
| **刷单套利** | 用小号跟着自己的 Thesis 交易来套奖励 |
| **公式不公开导致争议** | 用户不知道怎么算的，容易觉得不公 |

### 4.4 自建建议

如果要做这个机制，建议加三个约束：

1. **奖励与后验表现挂钩** —— 不只看「带来多少交易」，也看「跟随者是否赚钱」。这会自然抑制煽动性内容。
2. **奖励延迟发放** —— 如 7 天后结算，期间做刷单检测。
3. **公开计算规则** —— 哪怕简化版。不公开必然产生争议。

## 5. Clans：把交易变成团队运动

### 5.1 机制

**[三方 Odaily / Cryptobriefing / fomotrading.app]**

- 2026-08 上线，2026-09-01 开放邀请，当时已有 **150+ 个 Clan**
- **一个用户同时只能属于一个 Clan**
- 可被邀请加入
- Clan 标签展示在个人主页
- **独立 Feed**（成员交易优先展示）
- **独立周榜**（排行榜可筛选本周表现最好的 Clan）
- **汇总整段战绩的卡片**
- ⚠️ **不共池资金** —— 每个成员用自己的余额、自己承担风险

### 5.2 产品逻辑

```
之前：跟随全平台 → 信噪比低，谁都能进你的 Feed
现在：跟随自选小圈子 → 降噪，但风险集中
```

fomo 官方 newsletter 的表述（措辞已改写）：你可以找到并关注一个好的交易者，但如果还能盯住他的整个交易小组会怎样？看他们交易什么、怎么交易、把你的论述和他们的对比。去排行榜就能找到本周表现最好的 Clan。

### 5.3 为什么 Clan 对留存很关键

单人产品的留存靠习惯，团队产品的留存靠**社交义务**：

| 机制 | 留存作用 |
|---|---|
| 一人只能进一个 Clan | 制造稀缺与承诺，降低流动性 |
| Clan 周榜 | 每周重置的竞争目标 → 周期性回访 |
| 战绩卡 | 集体荣誉 → 站外传播 |
| 成员 Feed 优先 | 你的交易会被队友看到 → 社交压力 |
| 队友在交易 | 别人在场 → FOMO 本身 |

**这是把「孤独的交易」变成「有人看着的交易」。** Galaxy 引用 fomo 的核心洞察：竞品的用户独自交易，fomo 的用户公开交易，而这**改变了他们交易的频率**（措辞已改写）。

⚠️ 注意最后半句 —— 「改变了交易频率」既是商业上的好事（收入 = 交易量 × 费率），也是用户利益上的坏事。

### 5.4 风险

- **群体追新盘** —— 一群人一起冲同一个新币，风险高度集中
- **Clan 内部的信息不对称** —— 头部成员对底层成员的出货流动性效应更强
- **排他性造成的负面体验** —— 进不去好 Clan 的用户会感到被排斥

```
                    ┌──────────────────────────┐
                    │   KOL 分享推荐码 + 内容      │
                    │  （25% 分成驱动）            │

        ┌────────────────────────────────────────────────┐

        └────────────────────┬───────────────────────────┘
                             ▼
        ┌────────────────────────────────────────────────┐
        │   交易自动成为公开内容（默认公开）                    │

  │ → 促成交易   │    │ → 获得粉丝     │    │ → 站外传播   │
  └──────┬──────┘    └──────┬───────┘    └──────┬──────┘
         │                  │                   │
         │                  ▼                   │
         │          ┌──────────────┐            │
         │          │ 加入/组建 Clan │            │
         │          │ → 社交义务     │            │
         │          └──────┬───────┘            │
         │                 │                    │
         └─────────────────┼────────────────────┘
                           ▼
              ┌────────────────────────┐
              │  平台交易量 ↑ 收入 ↑      │
              │  → 更多返佣付出            │
              │  → KOL 更有动力分发        │
              └───────────┬────────────┘
                          │
                          └──────► 回到起点，循环放大
```

### 飞轮的四个加速器

| 加速器 | 作用 |
|---|---|
| **内容零成本供给** | 交易自动变成内容，用户不需要额外「发帖」 |
| **经济激励贯穿全链路** | 推荐有钱、内容有钱、折扣有钱 |
| **默认公开** | 不需要用户做发布决策，内容供给不会断 |
| **App Store 排名** | 增长本身带来排名，排名带来自然流量（fomo 2026-08 冲到美区 iOS 财经榜第 3，超过 Cash App **[三方]**） |

## 9. 增长机制的风险与伦理

### 9.1 机制本身的问题

| 机制 | 增长效果 | 伦理成本 |
|---|---|---|
| Referral 25% | 极强 | KOL 有动力推荐给不适合的人 |
| Trader Rewards | 强 | 激励煽动性内容 |
| Clans | 强留存 | 群体追涨、集中风险 |
| 实时推送 | 高转化 | 制造冲动交易 |
| 排行榜 + 分享卡 | 强传播 | 只展示赢家，扭曲期望 |
| 爆单故事 newsletter | 强传播 | 极端案例当常态推送 |

### 9.2 Galaxy 的定性

Galaxy 的研究对这套设计给出了一个很难反驳的判断（措辞已改写）：**这套机制之所以有效，部分原因在于它让交易感觉起来不像实际上那么有后果。** 排行榜、美观的 PnL 分享、实时信息流，这些让体验变得吸引人的手法，大量借用了成瘾性产品设计的方法论。当投机变得像刷 TikTok 一样，娱乐和金融风险之间的心理边界就被侵蚀了。

它同时指出：**这些不是否定社交交易的理由，而是需要严肃对待其设计的理由。**

### 9.3 自建时的可选缓解设计

如果要做一个既能增长又不纯粹收割用户的产品：

| 做法 | 效果 | 代价 |
|---|---|---|
| **亏损同样公开且同等显著** | 校正期望（fomo 默认公开已经做到一半，但 Feed 排序和分享卡仍偏向赢单） | 降低传播性 |
| **展示「跟随者平均收益」** | 最诚实的数据 | 头部用户反对 |
| **推送频控与冷静期** | 减少冲动交易 | 降低活跃度与收入 |
| **突出平均持仓时长** | 抑制剥头皮者的曝光 | 降低 Feed 刺激度 |
| **平仓事件延迟广播** | 减少踩踏 | 削弱「实时」卖点 |
| **新用户强制风险测试** | 筛掉完全不懂的人 | 降低转化率 |
| **Trader Rewards 与后验表现挂钩** | 抑制煽动性内容 | 机制更复杂 |

**每一条都是用增长换用户利益。** 这是明确的价值观选择，不是技术问题。至少要让团队清楚地知道自己在选什么。

## 10. 自建增长策略建议

### 第一阶段（0 → 1 万用户）：找到种子 KOL

- 不要撒网，找 **10–30 个中腰部交易 KOL**（粉丝 1 万–10 万）
- 给他们**定制分成（30%+）+ 专属数据看板 + 产品共建话语权**
- 头部 KOL 太贵且不缺渠道，中腰部粉丝黏性更高
- **同时解决冷启动**：这批 KOL 的交易本身就是初始 Feed 内容

### 第二阶段（1 万 → 10 万）：标准化 Referral + 排行榜

- 开放标准推荐码（25% 分成 + 10% 折扣）
- **排行榜必须先上线** —— 它是新用户「关注谁」的唯一答案
- 开始做 SEO 内容（对标竞品关键词）
- 应用商店 ASO

### 第三阶段（10 万 → 100 万）：Clan + Trader Rewards

- 团队机制放大留存
- 内容激励让 UGC 自我供给
- 开始做站外传播资产（分享卡、战绩海报）

### 必须提前建好的基础设施

1. **归因系统** —— 每笔交易要能追溯到来源（哪个 KOL、哪条 Feed、哪个排行榜位次）
2. **返佣对账** —— 精确、可查、可申诉。算错一次 KOL 就不推了
3. **反刷检测** —— 自推自、机器人、刷量套返佣
4. **Cohort 分析** —— 按获取渠道分层看留存，否则不知道哪个渠道是真有效
