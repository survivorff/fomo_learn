## A. 账户与身份

### A1–A2 登录即开户

**[官方]** 邮箱或 Apple ID 登录，**30 秒内**完成账户创建并自动生成自托管钱包，无助记词步骤。一个钱包跨全部支持的链，不需要按链分别建钱包。

这是整个产品的第一个转化杠杆。传统链上开户流程（装钱包 → 抄助记词 → 买 Gas 代币 → 跨链）在这里被完全消除。

### A3 生物识别（FaceID）

**[官方]** FaceID 在三个场景强制校验：

| 场景 | 是否需要 FaceID |
|---|---|
| 打开 App | ✅ |
| 出金 | ✅ |
| 导出私钥 | ✅ |
| 普通交易 | ❌（保证滑动买入的流畅度） |

设计意图明确：**交易路径要顺，资金外流路径要卡**。即使别人拿到你已解锁的手机，也无法提走资金或导出密钥。

### A4 私钥导出

**[官方]** 可随时导出私钥迁移到 Phantom / MetaMask 等钱包。这是「自托管」主张的硬证据 —— 如果 fomo 明天消失，资产仍在链上、仍由用户密钥控制。

⚠️ 注意 fomo 服务条款里的一处细节（**[三方]** insights4.vc 指出）：导出的私钥材料由 Privy 传输，密钥安全责任归用户。所以准确说法是**嵌入式自托管（embedded self-custody）**，不是传统券商账户，也不完全等同于用户独占密钥。

### A5 用户主页

**[官方/三方]** 展示内容：

- 投资组合与交易历史
- 交易量、粉丝数
- 战绩与**权益曲线（equity curve）**
- **平均持仓时长（average hold time）** ← 这个指标很关键
- Clan 归属

**平均持仓时长**是 fomo 引入的一个小而重要的创新。钱包追踪时代你只能看到一个地址在做什么，却无法判断背后这个人是什么风格。这个指标让跟随者能分辨「时间尺度和我匹配的交易者」与「几分钟就跑的剥头皮选手」（[Galaxy 研究](https://www.galaxy.com/insights/research/social-trading-fomo)，内容经改写）。

## B. 资金

### B1 法币入金

**[官方]** 2026-01 上线 **Coinbase 驱动的 Apple Pay 入金**，支持 Apple Pay / Google Pay / 借记卡。

效果数据：到 2026-06，**6.8 万用户通过 Apple Pay 完成人生第一笔加密资产购买，合计 $25M**。Galaxy 的评价是：Apple Pay 入金可能仍是把非加密原住民带上链的**最有效单一机制**。

⚠️ fomo 自身不做 KYC，但**支付合作方会做自己的合规检查**。

### B3 统一美元余额

**[官方]** 以 **USDC 作为可见的现金余额**，用美元计价展示。用户不需要为了交易而持有 SOL 或 ETH。

这个决策的三层价值：
1. 消费者心智对齐（余额 = 美元 = 现金）
2. PnL 用美元表达，直观
3. 消除「为付 Gas 而持币」的认知负担

⚠️ 但它不消除：稳定币脱锚风险、发行方风险、合约风险、以及路由过程中产生的敞口。

### B4 出金

**[官方/三方]** 可提到外部链上地址。**法币提现（银行）主要限于美国用户**，其他地区可用性因地而异。

### B5 带附言的转账

**[官方]** 2026-02 上线，转账可附文字和图片。把「转账」从金融动作变成社交动作。

## C. 发现（产品的真正核心）

### C1 社交 Feed

**[官方/三方]** 首页 Tab 是 Feed 而不是 K 线图 —— 这是 fomo 和所有竞品最直观的区别。

Feed 条目包含：

```
┌─────────────────────────────────────────┐
│ @trader_name   [Clan 标签]      2 分钟前 │
│ 🟢 买入 $TOKEN                           │
│ 入场价 $0.00042 · 仓位 $12,400           │
│ 实时 PnL  +34.2%  (+$4,240)             │
│ ─────────────────────────────────────── │
│ 💬 "这个盘的持仓分布很干净，前十占比不到 15%"  │
│    ← Thesis                             │
│ ─────────────────────────────────────── │
│ ❤️ 128   💬 34            [ 一键买入 ]    │
└─────────────────────────────────────────┘
```

Feed 类型：
- **全局 Feed**（Global）—— 全平台热门交易
- **关注 Feed**（Following / Friends Feed，2025-09 上线）
- **Clan Feed**（2026-08）—— 只看战队成员
- **代币 Feed**（2026-01）—— 单个代币下的交易与 Thesis

交互路径：**点条目 → 落到代币页且买入面板已展开 → 两次点击完成同仓建仓**。

### C2 排行榜

**[官方/三方]** 三类排行榜，多时间维度（24h / 7d / 30d 等）：

| 类型 | 排序维度 |
|---|---|
| 交易者排行榜 | 盈利能力、PnL |
| 代币排行榜 | 涨幅、交易量、持仓人数（按链） |
| Clan 排行榜 | 战队整体表现（周榜） |

排行榜的产品职能是**解决冷启动**：新用户不需要花一周刷 X 找人跟，一分钟就能筛出候选名单。

数据点：2026-08-31 官方 newsletter 提到排行榜上出现了第一个 **PnL 达 $1000 万** 的交易者 **[三方]**。

### C3 代币详情页

**[官方]** 单页聚合全部 DYOR 所需信息，目标是让研究过程「trivially easy」：

- 价格 K 线（TradingView，多周期）+ **Thesis 标注直接画在图上**
- **Top holders / 早期买入者**，含各自的买入时点和最新观点
- 持仓分布（holder composition）→ 用于判断风险
- 流动性、市值
- 项目社交链接（X / Discord / Telegram）
- **安全警告**（疑似恶意代币标记）
- 该代币下的交易 Feed 与评论

### C7 实时 Alert

**[官方]** 关注的交易者开仓时推送到手机。fomo 官网把 ALERTS 列为四大卖点之一，文案是「实时通知最强的人在买什么」。

这是社交交易的**转化引擎**：推送 → 点开 → 一键买。也是行为风险的来源（见 [10 风险合规与安全](10-风险合规与安全.md)）。

### C8 新盘监控

**[三方]** Pump.fun / Bonk.fun / Four.meme 的新发币上线即出现在列表，带安全评分。

⚠️ 注意：fomo **不是狙击器**。多个来源明确指出它没有 sniper 功能，终端用户仍会另开一个终端。

## D. 交易

### D1 现货 Swap

**[官方/三方]** 交互设计：

- **滑动买入（slide-to-buy）** —— 防误触，且有仪式感
- **美元预设金额快买**（2025-12 上线）—— $10 / $50 / $100 等，省去输入
- **Quick buys** —— 毫秒级别重要时的快速通道

**刻意收窄的交易面**：fomo 自己的对比文章承认，相比直接用 DEX 界面，用户对**路由和滑点的控制粒度更低**。这降低了认知负担，但把责任转移给了平台的路由与保护默认值。

⚠️ 公开文档**没有**披露审计过的执行质量统计，也没有完整的价格改善政策。薄流动性代币上，用户依然面临价格冲击、报价过期、MEV 和交易失败 —— 只是看不见了。

### D5 持仓与实时 PnL

**[官方]** 2025-10 上线「K 线图上的动态 PnL」。持仓和盈亏跨链在同一视图实时追踪 —— 这是多链交易者平时要用 Excel 拼的东西。

### D6 永续合约（Perps）

**[官方]** 2026-06-11 上线，执行在 **Hyperliquid** 和 **Trade[XYZ]**，fomo 只提供接口与社交层。

覆盖资产类别（官方列举）：

| 类别 | 标的举例 |
|---|---|
| Pre-IPO | SpaceX |
| 美股 | NVDA、GOOGL、AMD、MU、SNDK |
| 加密 | BTC、ETH、SOL、HYPE |
| 指数 | S&P 500、Nasdaq 100、Kospi 200、Nikkei 225 |
| 商品 | 原油、白银、黄金、铜、天然气 |

首版产品特性：
- **逐仓保证金（isolated margin）** —— 为了和现货体验统一
- 一键交易
- 止盈 / 止损（TP/SL），并**首次把高级图表带到移动端**
- 现货与永续统一的组合视图
- 复用现有 fomo 账户

Perps **完全接入社交层**：显示方向（多/空）、杠杆、仓位规模（notional）、仓位价值（equity），并进入 Feed、排行榜、Thesis、Profile。fomo 因此成为**第一个跨资产类别的统一社交图谱**。

🚫 **硬性限制**：Perps 由第三方协议提供，**不向美国人开放**（公民、居民、以及任何身处美国境内的人）。

## E. 社交

### E2 Thesis（最被低估的模块）

**[官方]** 2026-01 上线，2026-02 进入全局 Feed。用户可给一笔交易附一段文字说明理由，**这段文字带时间戳画在 K 线图上**。

为什么它重要：
1. **把交易从数据变成观点** —— 可被讨论、被引用、被验证
2. **是 Trader Rewards 的载体** —— 内容驱动交易可获奖励（见 F2）
3. **是护城河的一部分** —— 这是用户生产的、无法从链上抓取的独占数据

Web 版的代币页专门展示：Thesis 的撰写时间、作者、受欢迎程度。

### E3 评论系统

**[官方]** 演进路径：
- 2025-10：全持仓者可评论
- 2025-11：评论表情回应、互关关系
- 2025-12：楼层式回复
- 评论线程挂在 K 线图下方，让讨论紧贴价格走势，而不是散落在 Discord 和 X

### E4 Clans（战队）

**[三方]** 2026-08 上线，2026-09-01 开放邀请，当时 150+ 个 Clan。

规则：
- 一个用户同时只能属于**一个** Clan
- 可被邀请加入
- Clan 归属展示在个人主页
- Clan 有**独立 Feed**（成员交易优先展示）
- Clan 有**独立排行榜**（周榜）
- 有汇总整段战绩的**卡片**

⚠️ 重点：**不共池资金**。每个成员用自己的余额交易、自己承担风险。Clan 只决定「你先看到谁的交易」和「谁的名字上榜」。

本质是**把跟单范围从全平台收窄到自选人群** —— 降噪，但如果这群人一起追新盘，风险也会集中。

### E5 分享卡片

**[官方]** Perps 上线时同步扩展了「仓位半屏卡（position half sheet）」和「分享卡片」，承载更多信息。这是站外病毒传播的燃料 —— 社交平台上大量流传的 fomo 盈利截图就是这个功能的产出。

## G. 风控与安全

### G1 代币安全警告

**[官方]** 2025-09 上线。所有资产都能买，但**平台会对疑似恶意代币打警告标记**。

⚠️ 具体规则未公开。行业通行的检测项包括：合约权限（可增发 / 可冻结 / 可改税）、蜜罐检测、LP 锁定状态、持仓集中度、捆绑钱包（bundled insider wallets）、部署者历史。

Datawallet 的建议值得写进产品：**买入前检查是否有捆绑的内部人钱包，能筛掉最明显的陷阱**（内容经改写）。

### G3 地域限制

**[官方]** 限制跟着市场走，不跟着 App 走：

| 产品 | 美国用户 |
|---|---|
| 现货交易 | ✅ 可用 |
| Perps | 🚫 屏蔽 |
| 代币化美股（Robinhood Chain） | 🚫 屏蔽 **[三方]** |

原因是底层场馆（第三方协议）本身要求如此。

## H. 辅助

- **H1 Awaken 税务集成**（2026-01）—— 交易记录导出报税，这是消费级产品的必要配套
- **H2 应用内客服**（2026-02）—— 之前只有邮件；Trustpilot 上有少量一星评论抱怨模板化回复 **[三方]**
- **H3 内容运营** —— 日报、newsletter（fomoapp.beehiiv.com）、市场更新、Thesis 合辑、年度回顾
- **H4 多端同账户** —— 手机开仓、桌面平仓；通知设置、关注关系全端同步。Web 版到 2026-08 已占**总交易量约 25%** **[三方]**

## 自建优先级建议

| 优先级 | 模块 | 理由 |
|---|---|---|
| **P0（MVP 必需）** | A1 A2 B1 B3 C1 C3 C4 D1 D3 D5 E1 F1 F3 G1 | 缺任何一个，核心循环不成立 |
| **P1（留存关键）** | A5 C2 C7 D4 E2 E3 B4 | 决定用户会不会第二天回来 |
| **P2（护城河）** | E4 E5 F2 C5 C6 C8 H3 | 社交网络效应的来源 |
| **P3（扩张）** | D6 A4 B5 H1 H4 E6 | 有了规模再做 |
